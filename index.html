    Help & guide

    Overview

    Paste an AI answer into the left pane. The right pane shows the same text rewritten in a plainer, hand-typed style. Everything happens in your browser as you type, and your filters, rules and display preferences are saved locally.

    Text passes through three stages, in this order:

    1. Always-on tidying Trailing spaces are removed from the end of each line, and curly quotes become straight quotes.
    2. Filters The toggles in the top bar, applied left to right.
    3. Replacements Your own find-and-replace rules, applied top to bottom.

    Every filter shows a number when it has something to change in your current text, so you can tell what a toggle will do before you flip it. A dash means it would change nothing.

    Filters

    Each filter runs only when it is switched on. Turning one off never loses your original text — the left pane is untouched.

    Replacements

    The middle panel holds your own rules. Each rule swaps one exact piece of text for another, and they run from top to bottom after the filters.

    • Order matters. A rule sees the result of the rules above it. To move one, drag its handle, or point at the handle to bring out the up and down arrows, or focus the rule and press Alt + ↑ / ↓.
    • Spaces count. "* " with a trailing space is a different rule from "*". A ␣ marker appears when a field starts or ends with a space.
    • Switch instead of delete. The toggle on each rule turns it off without throwing it away.
    • Nothing is plain-text magic. Rules match literally, not as patterns, so . and * mean themselves.
    • Preview then save. Edits show up in the output immediately, but only Save stores them for your next visit.

    A useful starting set:

    *␣→-␣
    ###␣→(nothing)
    —→␣-␣
    🔹→-

    Here ␣ stands for a real space you would type.

    Import and export

    Export writes a JSON file holding your rules, their order and their on/off state. Import reads that file back, and also accepts the older {"find": "replace"} style, so any mapping file you saved before still loads. An imported set previews right away and waits for you to Save.

    Display

    The sliders button opens font size and font family for both panes. Changes preview as you make them, Cancel puts things back, and Save keeps them for next time.

    Shortcuts

    Ctrl/⌘ + S
    Save replacement rules
    Alt + ↑ / ↓
    Move the focused rule up or down
    Esc
    Close a dialog, popover or the rules panel

    Cautions

    • Check code and complex text. Stripping Markdown can eat characters that mattered, such as the asterisks in a code sample. Compare both panes before you trust the result.
    • Keep a backup. Your rules live in this browser's local storage, so clearing site data removes them. Export a copy now and then. A ready-made example lives on GitHub.
